# Study Planner

A simple Laravel web application for organizing study topics and keeping track of study progress.

## Features

- Add study topics
- View study topics
- Edit study topics
- Delete study topics
- Set a study date
- Set a priority
- Mark topics as completed or not completed
- Simple and clean user interface

## Technologies Used

- Laravel
- PHP
- Blade
- CSS
- Vite
- SQLite

## Installation

1. Clone the repository:

```bash
git clone https://github.com/filfordgian143/study-planner.git

2.Open the project folder:
cd study-planner
3.Install PHP dependencies:
composer install
4.Create the environment file:
cp .env.example .env
5.Generate the application key:
php artisan key:generate
6.Run the database migrations:
php artisan migrate
7.Install frontend dependencies:
npm install
8.Start the Laravel development server:
php artisan serve
9.In another terminal, start Vite:
npm run dev

Then open:

http://127.0.0.1:8000
